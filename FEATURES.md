# ArcGIS Pro Wayback Imagery Add-In - Feature Registry

This file maintains a running log of all features, capabilities, and constraints for the ArcGIS Pro Wayback Imagery Add-In according to project governance guidelines.

## Feature Registry

| Feature ID | Feature Name | Description | Status | Added / Modified |
|---|---|---|---|---|
| FT-001 | WMTS Capabilities Discovery | Automated retrieval and parsing of Esri Wayback WMTS Capabilities XML (`https://wayback.maptiles.arcgis.com/arcgis/rest/services/World_Imagery/MapServer/WMTS/1.0.0/WMTSCapabilities.xml`) extracting 190+ historical imagery releases with IDs, dates, titles, and tile URL templates. | Completed | 2026-08-21 |
| FT-002 | Hybrid Two-Tier Metadata Caching | Fast in-memory cache combined with local JSON disk cache (7-day TTL) and bundled offline snapshot fallback for sub-second tool responsiveness without network latency. | Completed | 2026-08-21 |
| FT-003 | Single-Layer Dynamic Map Management | In-place dynamic Cartographic Information Model (`arcpy.cim`) layer manipulation of `CIMTiledServiceLayer` / `CIMWMTSServiceConnection` in the active ArcGIS Pro map. | Completed | 2026-08-21 |
| FT-004 | Unified Time-Stepper Tool (.pyt) | Pure ArcGIS Pro Python Toolbox exposing `WaybackStepperTool` with dynamic parameter validation (`ToolValidator`) for ribbon, quick access toolbar, and geoprocessing pane execution. | Completed | 2026-08-21 |
| FT-005 | Navigation Modes | Support for Step Forward (newer), Step Backward (older), Jump to Specific Date, Jump to Latest Date, and Jump to Oldest Date. | Completed | 2026-08-21 |
| FT-006 | Zero External Dependencies & Offline Resilience | Operates with Python 3.11+ standard library and native `arcpy` / `arcpy.cim` with zero third-party package dependencies and graceful offline fallback. | Completed | 2026-08-21 |
| FT-007 | Comprehensive Documentation & Governance | Complete user guide (`documentation/user_guide.md`), developer guide (`documentation/developer_guide.md`), unit/mock test suite, and execution summaries (`.junie/reports/`). | Completed | 2026-08-21 |
| FT-008 | Interactive Timeline Slider Control Tool | Second toolbox tool (`WaybackSliderTool`) utilizing Esri slider parameter control (`controlCLSID`) and dynamic `updateParameters` validation to scrub through historical imagery dates and update the active map layer in real time without executing the tool. | Completed | 2026-08-21 |
| FT-009 | Fixed Layer Creation (CIM Type & URL) | Fixed `.lyrx` JSON template to use the concrete `CIMInternetServerConnection` type (not the abstract base class), strip the capabilities XML filename from the server connection URL, and include WMTS `version: "1.0.0"`. Also fixed `apply_release_to_cim_layer()` CIM object creation and added `derive_wmts_base_url()` helper. | Completed | 2026-08-24 |
| FT-010 | Improved Slider Responsiveness | Replaced the `hasBeenValidated` early-return guard with a layer-name comparison approach that reads the actual Wayback layer name from the map's Contents pane. This is durable across ArcGIS Pro validation cycles (which may recreate tool instances) and prevents infinite loops while keeping the slider responsive. | Completed | 2026-08-25 |
| FT-011 | Save Current Layer (Standalone Freeze) | "Save Current Layer" checkbox (`GPBoolean` parameter) that creates an independent frozen copy of the current Wayback imagery release as a standalone layer named "Saved: Imagery YYYY-MM-DD". The standalone name pattern avoids matching `WAYBACK_LAYER_REGEX` so `find_wayback_layer()` won't treat it as the adjustable layer. Auto-resets after action. | Completed | 2026-08-24 |
| FT-012 | Metadata Identification Support | Layers include metadata service URL information in their descriptions. Each release's `WaybackRelease` model exposes `release_number` (extracted from tile URL) and `metadata_service_url` properties pointing to the correct metadata MapServer URL (e.g., `World_Imagery_Metadata_2023_r11/MapServer`). | Completed | 2026-08-24 |
| FT-013 | Identify Imagery Metadata Tool | `IdentifyMetadataTool` reads the active map view's center coordinates, uses the MapServer `identify` endpoint (not layer 0 query) with scale-aware sublayer selection, and outputs acquisition date, provider, source, resolution tier, and accuracy to the geoprocessing output. | Completed | 2026-08-25 |
| FT-014 | Map & Layer Dropdown Selection | The Identify Imagery Metadata tool now provides a dynamic dropdown of all maps in the project and a second dropdown of Wayback imagery layers (managed + saved) within the selected map, defaulting to the managed adjustable layer. Layer list refreshes automatically when the map selection changes. | Completed | 2026-08-25 |
| FT-015 | Scale-Aware Metadata Query | The metadata query uses the MapServer `identify` REST endpoint with a synthetic map extent computed from the current map scale, enabling automatic selection of the correct resolution-specific metadata sublayer (14 sublayers from 1.9cm to 150m). Correctly parses `SRC_DATE` as YYYYMMDD integer and prefers `SRC_DATE2` human-readable date. | Completed | 2026-08-25 |
| FT-016 | Local Changes & Capture Date Discovery Tool | New dedicated geoprocessing tool `WaybackCaptureDateTool` that discovers Wayback releases with actual local imagery changes at the active map viewport via tilemap API, resolves true ground capture dates and provider attribution via metadata identify endpoint, provides dropdown formatted as `YYYY-MM-DD (Wayback YYYY-MM-DD - Provider)`, enforces configurable scale guards (default 1:24,000), and supports batch-adding all changed releases as standalone layers. | Completed | 2026-09-16 |
| FT-017 | Persistent Full-Path File Logging | Centralized logging subsystem (`wayback_addin.logger`) configuring a `RotatingFileHandler` writing structured log entries with timestamp, level, module, and message directly to `wayback_addin.log` in the project root directory, integrated across all add-in modules and geoprocessing tools. | Completed | 2026-09-25 |
| FT-018 | Authoritative Catalog Integration & Dual-Mode Metadata Querying | Integration of official Esri `waybackconfig.json` catalog providing exact release numbers, ArcGIS Online Item IDs, item URLs, and authoritative `metadataLayerUrl` endpoints with two-digit zero-padded release numbers (`r01`..`r07`). Implemented dual-mode metadata resolution using direct sublayer point intersection query (`/MapServer/{layerId}/query` with `layerId = max(0, min(13, 23 - zoom))`) as primary approach with graceful fallback to MapServer `/identify`. | Completed | 2026-09-25 |
