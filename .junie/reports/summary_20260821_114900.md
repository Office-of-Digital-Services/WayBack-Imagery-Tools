> "I'd like to create a single purpose Python addin for ArcGIS Pro - these add user interface functionality to the interactive application GUI. The add-in should allow for a time slider, either in a top ribbon, or in a floating item over the map display. The time slider should control which date of imagery is pulled from Esri's Wayback imagery WMTS service. Available dates should be read from the available layers on the service, allowing the user to select a specific date and have a base layer in the map controlled by the add-in change to imagery as of that date. The service is located at `https://wayback.maptiles.arcgis.com/arcgis/rest/services/World_Imagery/MapServer/WMTS/1.0.0/WMTSCapabilities.xml`. ## 2. Architectural Understanding & Key Technical Decisions

1. **Architecture Pattern & Extension Format**:
   - Implemented an ArcGIS Pro Python Toolbox (`WaybackImagery.pyt`) with dynamic parameter validation (`ToolValidator`), exposing both a unified stepper tool and dedicated one-click tools for the ArcGIS Pro Ribbon and Quick Access Toolbar.
   - Built a modular core package (`wayback_addin/`) with strict separation between data models, XML parser, two-tier cache engine, and map layer management.

2. **Single-Layer In-Place CIM Modification**:
   - Uses ArcGIS Pro Cartographic Information Model (`arcpy.cim`) to modify the `CIMTiledServiceLayer` definition directly in place (`layer.getDefinition('V3')` -> update `CIMWMTSServiceConnection` properties -> `layer.setDefinition()`).
   - Prevents table-of-contents clutter by modifying the existing layer rather than deleting and re-adding layers on every date switch.

3. **Two-Tier Hybrid Caching & Zero-Latency Stepping**:
   - Combined in-memory dictionary lookup for the active session with a persistent local JSON disk cache with a 7-day TTL and bundled static snapshot fallback (`fallback_capabilities.json`), ensuring instantaneous sub-second interactive stepping and complete offline resilience.

4. **Zero External Dependencies**:
   - Engineered exclusively using the Python 3.11+ standard library (`urllib`, `xml.etree.ElementTree`, `json`, `datetime`, `pathlib`, `re`) and native `arcpy` / `arcpy.cim`.
